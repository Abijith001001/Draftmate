Section method

For a plane perpendicular to VP, set its angle to HP and axis crossing. For a vertical plane, set its angle to VP and distance from the axis; use the elevation for true shape only when the plane is parallel to VP.

Development logic

Use true lengths to lay out each face. Cone uses sector geometry; prism uses a perimeter strip; pyramid uses radial faces from the apex.

Construction steps

  1. Select a solid and enter dimensions.
  2. Calculate the cut section or the development surface.
  3. Use the true shape and the development strip to complete the engineering drawing.
